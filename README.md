# Punit Jain - Portfolio

Static portfolio site. Deployed on Vercel.

- index.html - the whole site (single page)
- gsap.min.js, scrolltrigger.min.js, lenis.min.js - animation libraries
- punit.webp - profile photo
- certs/ - certificate images and PDFs
- PUNIT_JAIN_RESUME.pdf - resume

No build step. Vercel serves these files as-is
(Framework Preset: Other, no build command).
